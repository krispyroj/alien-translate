# Alien Translate v1.0.0 👽

โปรแกรมเล็ก ๆ สำหรับ Windows ที่ช่วยแปลงข้อความเมื่อเผลอพิมพ์ผิดแป้นไทย–อังกฤษ

## ดาวน์โหลด

ดาวน์โหลด **AlienTranslate.exe** ด้านล่าง แล้วเปิดใช้งานได้เลย ไม่ต้องติดตั้ง โปรแกรมจะอยู่ที่ไอคอนหัวเอเลี่ยนสีมิ้นต์ใน system tray

## ใช้งาน

- คลุมข้อความแล้วคลิกขวา เพื่อเลือกอังกฤษ → ไทยเกษมณี หรือไทยเกษมณี → อังกฤษ
- คัดลอกข้อความแล้วกด **Ctrl+Alt+J** เพื่อเปิดเมนูแปลง
- แก้ Caps Lock ได้ทั้งแป้นไทยและอังกฤษ
- ชี้ข้อความแล้วกด **Ctrl+Alt+H** เพื่ออ่านข้อความจากแอปที่รองรับ
- ใน LINE ใช้คำสั่ง “คัดลอกข้อความที่เลือก” เพื่อเปิดเมนูแปลง

แปลงข้อความในเครื่องตามตำแหน่งปุ่ม ไม่ใช่การแปลความหมาย การอ่านข้อความขึ้นอยู่กับการรองรับ Windows UI Automation ของแอปต้นทาง หากคลิกขวาไม่ขึ้น ให้ใช้วิธีคัดลอกแทน

ต้องใช้ Windows พร้อม .NET Framework 4.5 ขึ้นไป รุ่นนี้ยังไม่มีลายเซ็นดิจิทัล
